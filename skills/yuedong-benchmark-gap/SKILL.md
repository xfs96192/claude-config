# 悦动稳享业绩基准差距测算

自动读取收益测算数据，计算并展示 9T310060（悦动6号）和 9T310070（悦动7号）的预期年化收益率与业绩基准的差距及需补金额。

## 数据源

```
/Users/fanshengxia/Desktop/周报V2/数据/收益测算数据/
├── 悦动稳享资产配置-YYYYMMDD.xlsx  → 业绩基准下限、预期年化收益率、低波资产占比、产品静态收益率(费后)
└── 悦动稳享底表-YYYYMMDD.xlsx      → 净资产(亿)、累计年化、运作天、剩余天
```

## 计算公式

```
年化差距 = 预期年化收益率 - 业绩基准下限              (bp)
净值差距 = |年化差距| × (运作天 + 剩余天) / 365       (百分点)
需补金额(万) = 净值差距 × 净资产(亿) × 10000 - 100    (每行扣减100万未考虑因素)
```

## 执行流程

1. 扫 `悦动稳享资产配置-2026*.xlsx` 和 `悦动稳享底表-2026*.xlsx`，按日期匹配
2. 筛选日期 ≥ 20260226 的可用日期
3. 对每个日期的每个产品（9T310060/9T310070），从资产配置取 `业绩基准下限`、`预期年化收益率`，从底表取 `净资产(亿)`、`累计年化`、`运作天`、`剩余天`
4. 按上述公式计算每个日期每个产品的差距和需补金额
5. 按以下横排格式输出表格（追加到最新日期）：

| 日期 | 6号净资产 | 6号实际年化 | 6号预期年化 | 6号差距 | 6号需补(万) | 7号净资产 | 7号实际年化 | 7号预期年化 | 7号差距 | 7号需补(万) | 合计需补(万) |

## 列取值说明

- **净资产**: 底表 `净资产(亿)`，格式 `XX.XX亿`
- **实际年化**: 底表 `累计年化`，反序列化为百分数（文件中的小数直接 ×100 为%）
- **预期年化**: 资产配置 `预期年化收益率`，处理可能的 `%` 前缀
- **差距(bp)**: `(预期年化 - 业绩基准) × 10000`，保留整数或1位小数，负值前加 `-`
- **需补(万)**: 计算后四舍五入取整
- **合计需补(万)**: 当日 6号 + 7号 需补金额

## 输出要求

- **只输出表格**，不需要每次重复解释计算逻辑
- 在表格下方附简要变化说明（3-5行要点）
- 如出现低波占比或静态收益率异常波动（单周变化 >10pp 或 >20bp），特别标注
- 合计列加粗

## 注意事项

- `累计年化` 在底表中为小数（如 0.0389 = 3.89%），不需要额外除以100
- `净资产(亿)` 在底表中，不在资产配置中
- 百分比列可能包含 `%` 符号，需统一用 `str.replace('%','')` 处理
- 文件匹配用文件名日期匹配，不是文件修改时间
- 4/29 数据历史上被手动调整过（NAV+8bp/+10bp，静态还原至4/23水平），skill生成时使用原始文件数据
