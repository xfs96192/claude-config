# 产品净值涨跌归因 Skill

把单只或多只产品在多个区间（近1月/3月/6月/今年以来/任意自定义）的净值涨跌幅，按资产分类拆分到「债券 / 转债 / 衍生品-兴合3号 / 衍生品-兴合4号」（或用户自定义分类）。

## 何时使用

满足任意一条即触发：
1. 用户给出"净值走势图xxx.xlsx"+"资产收益贡献_xxxxx.xlsx"，要求分析净值涨跌或归因到资产类别
2. 用户说"对比A产品和B产品的净值走势并归因"、"把净值涨跌拆到债券/转债/衍生品"、"产品评价/产品业绩拆解/收益归因"
3. 用户给出资产分类清单（如转债账户、衍生品账户），让分析按分类聚合

## 归因方法（核心）

```
对每个 (产品, 区间)：
  1. 读资产收益贡献明细的「资产名称」与「资产杠杆后收益(元)」
  2. 按分类规则把每条资产打上类别标签（衍生品-兴合3号 / 衍生品-兴合4号 / 转债 / 债券）
  3. 取费用：6项「期间管理人报酬/销售服务费/托管费/超额管理费/税费/交易费用」(每行相同，取第一行加总)
  4. 总费前收益 = sum(资产杠杆后收益)
  5. 费后收益 = 总费前 - 费用合计  （理应≈净值涨跌×日均规模，用来核对）
  6. 净值涨跌幅% = 从净值文件取 区间末日净值 / 区间首日净值 - 1
  7. 各类别归因净值涨跌% = (类别费前收益 / 总费前收益) × 净值涨跌幅%
```

费后收益与产品收益率的核对：`费后收益 / 期间客户本金日均规模 ≈ 产品收益率(%)`（报表里直接给的列），可用来交叉验证数据完整性。

## 执行步骤

### Step 1：识别用户输入

- 净值数据文件路径（每只产品一份 xlsx，sheet 通常叫"净值走势图"，包含两列：日期、单位净值）
- 资产收益贡献明细文件路径（每只产品 × 每个区间一份 xlsx，sheet 通常叫"资产收益贡献信息0"，含41列标准模版字段）
- 截止日期（不指定就用净值文件最新日期）
- 想要的区间清单（不指定就默认"近1月/3月/6月/今年以来"）

### Step 2：生成 config.json

在用户工作目录下生成 `nav_attribution_config.json`：

```json
{

  "periods": {

    "近3个月": "2026-02-20",
    "近6个月": "2025-11-20",
    "今年以来": "2025-12-31"
  },
  "ytd_start": "2025-12-31",
  "products": [
    {
      "name": "悦动1M",
      "code": "9K731010",
      "nav_file": "/path/to/净值走势图_悦动1M.xlsx",
      "nav_sheet": "净值走势图",
      "contribution_files": {
        "近1个月": "/path/to/资产收益贡献_9K731010_20260420_20260520.xlsx",
        "近3个月": "/path/to/资产收益贡献_9K731010_20260220_20260520.xlsx"
      },
      "contribution_sheet": "资产收益贡献信息0"
    },
    {
      "name": "悦动9M",
      "code": "9K210030",
      "nav_file": "/path/to/净值走势图_悦动9M.xlsx",
      "contribution_files": {
        "近1个月": "/path/to/资产收益贡献_9K210030_20260420_20260520.xlsx",
        "近3个月": "/path/to/资产收益贡献_9K210030_20260220_20260520.xlsx"
      }
    }
  ],
  "classification_override": null,
  "output_dir": "/path/to/output"
}
```

字段说明：
- `periods`: 字典 `{区间名: 区间起始日}`，截止日统一为 `end_date`。归因仅对**有contribution_files的区间**执行，纯涨跌幅对全部区间执行。
- `ytd_start`: 走势对比图的起始日，默认与"今年以来"相同
- `nav_sheet` / `contribution_sheet`: 可省略，默认值见上
- `classification_override`: 可选；填 `{"类别名": ["资产名1", "资产名2"]}`，**会与默认规则合并**（同名类别用override的列表替换，新类别追加）；填 `null` 用默认

读取 `summary.md` 在对话里贴出，主要展示：
1. **净值涨跌幅对比表**（区间 × 产品 × 涨跌幅）
2. **归因汇总表**（产品 × 区间 × 类别 → 归因净值涨跌%）
3. **归因解读**：哪个类别是核心贡献/拖累，产品间差异主因

## 输入数据格式约定

### 净值数据 xlsx
- 第一个sheet（默认名"净值走势图"）
- 列：`日期`、任意一列产品净值（自动取第二列）
- 日期类型：可被pandas.to_datetime识别即可

### 资产收益贡献明细 xlsx
- sheet 名 `资产收益贡献信息0`（脚本会兜底找含"资产收益贡献"的sheet）
- 必需列：`资产名称`、`资产杠杆后收益(元)`、`期间管理人报酬(元)`、`期间销售服务费(元)`、`期间托管费(元)`、`期间超额管理费(元)`、`期间税费(元)`、`期间交易费用(元)`、`期间客户本金日均规模(元)`、`产品收益率(%)`、`期末产品净资产(元)`

## 常见情况

- **缺某些区间的归因文件**：脚本会跳过对应归因，仅算净值涨跌幅，并在summary中说明。
- **多产品对比**：自动生成 PNG（单位净值+归一化涨跌幅两子图）。
- **归因后类别归因加总 ≠ 净值涨跌**：通常因为有费用扣减——本方法约定`归因占比×净值涨跌`已隐含费用按类别比例分摊，类别归因加总会等于净值涨跌幅（在该方法下是恒等式）。
- **某资产同时可能匹配多个类别**：用户override优先于默认；override内部冲突时报错。

## 与相关skill的区分

- `product-benchmark-report`：净值 vs 业绩基准对比，不做资产归因。
- `caifubu-equity-performance`：单独分析委外权益部分。
- 本skill的核心是**对总净值涨跌做资产分类归因**，不依赖基准。
