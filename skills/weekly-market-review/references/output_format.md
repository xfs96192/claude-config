# 周报输出格式参考

## 完整结构模板

```markdown
# 本周市场回顾

{债券段落}
{权益段落}
{转债段落}

# 市场回顾及操作

{净申购文字或"本周开放式产品合计净申购数据暂缺"}；本周资金资金面维持宽松，隔夜与7d在1.45-1.55附近。债券方面，10月以来买入1-2Y左右信用债合计11亿左右，加权久期1.2Y左右，加权平均收益率1.84%附近。同业存单买入约4亿，久期0.8年收益率1.65%附近。基金方面，价值回报、资源优势等含权日开产品根据申购款比例配置保持权益仓位及配置 部分债券基金保持流动性。

# 后市观点及下一步操作计划（债券）

**二、后市观点及下一步操作计划**

**债券部分：**
{资金面判断，央行操作，DR007预期运行区间}。{基本面与政策定调}。{中短端判断}；{长端判断}，预计{曲线形态}。

**操作上：**
以{整体思路}。**利率债**：{中短端策略}；{长端策略}。**信用债**：{信用债配置策略}。{整体组合管理}。
```

## 各段落写作规范

### 债券段落（80-120字）

- 开头：描述本周债市整体格局和主要驱动因素（1句）
- 利率债：逐一列出 1Y/3Y/5Y/10Y/30Y 国债活跃券的具体 bp 变动
- 信用债：列出 AA+ 城投债 6M/1Y/2Y/3Y 各期限具体 bp 变动
- 结尾：点出1-2个关键驱动因素（资金面/政策/央行/机构行为）

示例格式：
> 本周债券市场主要受[因素A]、[因素B]影响，整体呈现[格局]。利率债方面，1年、3年、5年、10年和30年国债活跃券收益率分别较上周变动Xbp、Xbp、Xbp、Xbp和Xbp，[曲线形态描述]。信用债方面，AA+城投债收益率[整体方向]，6个月、1年、2年和3年期品种分别变动Xbp、Xbp、Xbp和Xbp。[驱动因素2-3句]。

### 权益段落（80-120字）

- 开头：整体方向和主要原因（1句）
- 指数：上证指数和沪深300的具体涨跌幅（精确到两位小数）
- 行业：涨幅靠前 3-4 个行业，跌幅靠前 3-4 个行业（只列名称，不写具体涨跌数字）
- 驱动因素（1-2句）

示例格式：
> 本周权益市场[整体方向]，[主要原因]。上证指数全周[涨/跌]X.XX%，沪深300指数[涨/跌]X.XX%。行业表现分化显著，涨幅靠前的为[行业1]、[行业2]、[行业3]；跌幅靠前的包括[行业A]、[行业B]、[行业C]。[驱动因素]。

### 转债段落（60-80字）

- 中证转债指数具体涨跌幅
- 市场结构特征（偏股/偏债/均衡；估值高低）
- 驱动因素与短期建议

示例格式：
> 转债方面，本周转债市场[方向]。中证转债指数全周[涨/跌]X.XX%。市场结构上，[结构特征]。[驱动因素]，短期建议[操作方向]。

### 后市展望（债券，200-250字）

- 资金面：央行操作预期，DR007 运行区间
- 基本面：经济数据走向，政策定调
- 中短端策略：明确判断和操作方向
- 长端策略：明确判断和操作方向
- 信用债策略：等级偏好，久期偏好
- 整体组合方向

## 语言风格要求

- 简洁专业，资管机构内部口径
- 不出现"根据数据"、"JSON显示"、"数据表明"等提示性表述
- bp 变动格式：`-3.10bp`、`+2.5bp`（有符号，两位小数）
- 指数涨跌格式：`+1.13%`、`-0.93%`（有符号，两位小数）
- 连贯流畅，避免条目式罗列
