 你的ROIC实际上是增量的roic是吗                                                                                                                                                        
                                                                                                                                                                                        
⏺ 是的，准确说是增量营收 / 增量资本，而非传统意义上的 ROIC。                                                                                                                            
                                                                                                                                                                                        
  公式回顾：                                                                                                                                                                            
                                                                                                                                                                                        
  roic_t = (revenue_sum_t − revenue_sum_{t-12})                                                                                                                                         
           ─────────────────────────────────────                                                                                                                                        
           (invested_capital_t − invested_capital_{t-4})                                                                                                                                
                                                                                                     
  这与标准 ROIC 有两处本质区别：                                                                                                                                                        
                                                                                                   
  ┌──────────┬─────────────────────────────────┬─────────────────────────┐                                                                                                              
  │   维度   │             本指标              │        传统 ROIC        │
  ├──────────┼─────────────────────────────────┼─────────────────────────┤                                                                                                              
  │ 分子     │ 营收增量（3年跨度）             │ NOPAT（利润，当期水平） │
  ├──────────┼─────────────────────────────────┼─────────────────────────┤                                                                                                              
  │ 分母     │ 资本增量（1年变化）             │ 投入资本（存量水平）    │                                                                                                              
  ├──────────┼─────────────────────────────────┼─────────────────────────┤                                                                                                              
  │ 单位解释 │ 每新增1元资本，带来多少新增营收 │ 存量资本的盈利能力      │                                                                                                              
  └──────────┴─────────────────────────────────┴─────────────────────────┘                                                                                                              
                                                                                                     
  所以本指标衡量的是"边际扩张效率"——行业新投入的资本能否有效转化为营收增长，而非行业存量资产的盈利回报。白酒行业 2025Q3 的值 2.53                                                       
  表示：新增1元资本对应3年内营收增加2.53元，但这个值对行业横向比较更有意义，不能与标准 ROIC（通常5%~20%区间）直接比较。
                                                                                                                                                                                        
  实际使用时的注意事项：                                                                                                                                                                
  - 当分母（新增资本）接近0时，值会极度放大（如重资产行业某年没有净融资但收入仍在增长）              
  - 分子用营收增量而非利润增量，高毛利行业（白酒）和低毛利行业（贸易）的值没有可比性                                                                                                    
  - 如果想改为更标准的口径，可以把分子换成gross_profit_sum的增量，分母口径不变
